HW1 uv exercise — Qianhao Meng

1. Check uv version
Command:uv --version
Result:uv 0.12.10

2. Create the HW1 virtual environment with Python 3.12.9
Commands:
mkdir -p "$HOME/.virtualenvs"
uv venv --python 3.12.9 "$HOME/.virtualenvs/HW1"
source "$HOME/.virtualenvs/HW1/bin/activate"
python --version
python -c "import sys; print(sys.executable)"

Result:
Created and activated the HW1 virtual environment.
Python version: 3.12.9
Python executable: /Users/tommeng/.virtualenvs/HW1/bin/python


3. Install packages from the provided requirements.txt
Command:
uv pip install --python "$HOME/.virtualenvs/HW1/bin/python" -r ../requirements.txt
python -c "import requests; print(requests.__version__)"

Result:
Installed the required packages in the HW1 environment.
requests version: 2.25.0

4. Downgrade requests to 2.24.0
Command:
uv pip install --python "$HOME/.virtualenvs/HW1/bin/python" "requests==2.24.0"

"$HOME/.virtualenvs/HW1/bin/python" -c "import requests; print(requests.__version__)"

"$HOME/.virtualenvs/HW1/bin/python" -c "from importlib.metadata import version; print(version('requests'))"

Result:
requests was downgraded to 2.24.0, verified using importlib.metadata.
Importing requests failed on Python 3.12.9 because its old urllib3
dependency is incompatible with Python 3.12.

5. Upgrade requests to the latest version
Commands:
uv pip install --python "$HOME/.virtualenvs/HW1/bin/python" --upgrade requests urllib3
"$HOME/.virtualenvs/HW1/bin/python" -c "import requests, urllib3; print('requests:', requests.__version__); print('urllib3:', urllib3.__version__)"

Result:
requests: 2.34.2
urllib3: 2.8.0
Both packages imported successfully after the upgrade.

Latest installed version:2.34.2
