# HW1 - Shubham Gupta

This submission implements the evolve function for Conway's Game of Life.
The original file includes two tests, for a still-life block and a blinker.
Both tests pass when running python game_of_life.py in the HW1 environment.

Each cell's next state is calculated from the original board, using its eight
neighbors. Cells beyond the board are treated as dead. The result is built
in a new list so updates happen together.

Run the checks from this folder with the HW1 environment activated:

    python game_of_life.py

Keep work in Homeworks/HW1/Shubham_Gupta and exclude the HW1 environment from
the submission.
