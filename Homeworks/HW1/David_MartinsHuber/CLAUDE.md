## Files

- game_of_life.py: Implementation of the Game of Life.

## Implementation Details

- The game is happening on a rectangular grid of nxn, each cell of the grid as the value either of 1 or 0. 
- A value of 0 represents a dead cell, and 1 represents a living cell.
- The function should return a new grid representing the next generation.
- The original input grid should not be modified.
