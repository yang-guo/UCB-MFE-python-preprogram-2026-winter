# HW1 Submission

This folder is my HW1 submission for exercises covering Git, uv package management with Python 3.12.9, and Conway's Game of Life. The required submission files are `git.txt`, `uv.txt`, `CLAUDE.md`, and `game_of_life.py`.

In `game_of_life.py`, `evolve(initial_state)` is currently an unimplemented placeholder. The two supplied assertions check that a 2-by-2 block stays unchanged and that a vertical line of three live cells becomes a horizontal line.
