Commands I used, run from Homeworks/HW1/Theo_Basseras/ (Windows, Git Bash).

1. Create a virtual environment called HW1 with Python 3.12.9
   uv venv HW1 --python 3.12.9
   source HW1/Scripts/activate
   (PowerShell: .\HW1\Scripts\Activate.ps1 ; macOS/Linux: source HW1/bin/activate)

2. Install the packages from the requirement file Homeworks/HW1/requirements.txt
   uv pip install -r ../requirements.txt

3. Downgrade the requests library to version 2.24.0
   uv pip install requests==2.24.0

4. Upgrade the requests library to the latest
   uv pip install --upgrade requests

5. What's the latest version of requests?
   uv pip show requests
   -> Version: 2.34.2 (latest on 15 October 2026)
