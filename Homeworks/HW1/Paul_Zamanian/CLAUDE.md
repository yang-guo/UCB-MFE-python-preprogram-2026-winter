My HW1 submission for the UCB MFE Python pre-program: git, Claude Code, uv and Conway's Game of Life.

- `game_of_life.py`: `evolve(initial_state)` returns the next generation. Both test cases from the starter are kept.

## Notes

- The board is finite and cells outside it count as dead.
- The next board is built from the original one, so all cells update at the same time and the input isn't modified.
- The `HW1/` virtual environment stays local and isn't committed.
