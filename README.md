# HW1: Jinmeng Pan

This folder contains the Git exercise, a record of the uv package-management
exercise, and Conway's Game of Life implementation.

Use the local `HW1` virtual environment with Python 3.12.9. Run
`python game_of_life.py` from this folder to check the two supplied examples.
Cells outside the board are dead. `evolve` returns a fresh board and does
not modify its input. Keep both supplied assertions.

The `HW1/` environment is local only and must be excluded from submission.

Local setup check: Claude Code 2.1.291 was launched in this directory and the
workspace prompt completed. The CLI reported that no account was logged in;
use `/login` in Claude Code before requesting model assistance.
